# Development increments
1. Foundation and auth hardening: email verification, password reset, MFA, recovery, account activation.
2. Professional profile editor, ADR Professional ID issuance and affiliation verification.
3. Secure invitations, matter membership administration and permission evaluation.
4. Matter Hub CRUD, tribunal constitution, calendar and document register.
5. Venue provider registration and provider dashboard.
6. Venue inventory, availability, customer booking dashboard and booking engine.
7. Typist and professional services marketplace.
8. Dynamic fee builder, invoice generator and separate expense ledger.
9. Cloud repository linking, tribunal-change handover and reconciliation.
10. Audit, monitoring, penetration testing, backups and production deployment.

Each increment needs a requirements list, migration, UI, frontend and backend validation, RLS tests, acceptance tests and developer handover notes.
